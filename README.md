Swag Labs E-Commerce Website – Manual Testing

Project Overview
This project involves manual functional testing of the Swag Labs (SauceDemo) e-commerce web application. The objective was to evaluate the application's core functionalities, identify potential defects, validate expected behavior, and document test execution results using standard software testing practices.

Application: [https://www.saucedemo.com/](https://www.saucedemo.com/)
Testing Type: Manual Functional Testing
Testing Approach: Black Box Testing
Environment: Windows 11 | Google Chrome

Modules Tested

* Login: Valid and invalid login scenarios, authentication, and logout.
* Product Listing: Product visibility, product details, and sorting functionality.
* Shopping Cart: Adding and removing products, cart count, and cart validation.
* Checkout: Customer information validation, order overview, pricing calculations, and order completion.
* Application Navigation: Menu functionality and application state management.

Testing Deliverables
The Excel workbook contains:

* Detailed manual test cases with unique test case IDs.
* Test scenarios organized by application module.
* Actual and expected result documentation.
* Test execution status (Pass, Fail, and Not Executed).
* Bug report documentation with severity and priority.
* Test execution summary and dashboard.
* Test data and expected checkout calculations.

Defect Identified
Bug Title: Reset App State functionality does not reset the application correctly.
Observed Behavior: After using the Reset App State option, the application state does not reset immediately on screen. A browser refresh (F5) is required to restore the expected state.
Status: Documented for investigation (refer to the Excel workbook for recorded defect details).

Test Execution Highlights
Successfully completed an end-to-end purchase flow involving all six available products:

* Cart count: 6 products
* Item total: $129.94
* Tax: $10.40
* Grand total: $140.34
* Successful checkout and order confirmation
* PDF order confirmation generation

Note: Only executed test cases are marked as Pass or Fail; unexecuted scenarios are clearly identified as Not Executed.
